# Mahmudul Cybersecurity Portfolio — Version 2

Responsive static website with a separate browser-based visual editor.

## Files
- `index.html`: portfolio page.
- `styles.css`: visual design, colors, responsive layout.
- `script.js`: mobile menu and footer year.
- `editor.html` and `editor.js`: visual form, live preview, accent-color selection, reset, JSON settings download.

## Preview
Extract the ZIP. Open `index.html` to view the portfolio, or `editor.html` to open the visual editor.

## Editor limitation
The editor previews changes and downloads a JSON settings file. It does **not** directly rewrite `index.html` or publish the live site. Use the downloaded values to update the website source, or ask for the source files to be updated from those settings.

## Publish using GitHub Pages
1. Create a GitHub repository, for example `mahmudul-portfolio`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Use the deployment URL GitHub Pages provides.

## Before publishing
Verify exact certification names and issuers, review learning totals, add a public email only if desired, and only share security reports/screenshots you're authorized to publish. Remove private IPs, credentials, tokens, and third-party data.
